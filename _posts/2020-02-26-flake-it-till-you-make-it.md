### Project Overview
Built an end-to-end supply chain analytics solution tracking **10+ KPIs** across 15 suppliers, 6 warehouses, and 8,000+ transactions.

### Key Achievements
* **Interactive Dashboard:** Developed a 4-page Power BI dashboard with deep drill-down capabilities.
* **Cost Saving:** Identified delivery performance gaps, saving a potential **12%** in late delivery penalties.
* **Data Automation:** Streamlined data processing using Python and Pandas.

### Technologies Used
* **Languages:** Python (Pandas, Matplotlib, Seaborn), SQL.
* **Tools:** Power BI, Excel.
